## 설치 방법

1. 받은 파일을 두 번 클릭해요.
2. **"Windows의 PC 보호"** 창이 뜨면 **추가 정보** → **실행**을 눌러요.
   (유료 코드 서명을 하지 않은 프로그램이라 뜨는 안내예요.)
3. 설치가 끝나면 바탕화면의 **AI 글 탐지기** 아이콘으로 켜요.
4. 처음 한 번은 AI 모델(약 2.7GB)을 내려받아요. 화면 위에 진행률이 보여요.

### 브라우저가 다운로드를 막을 때
- **Edge**: 다운로드 목록에서 파일 옆 **⋯** → **유지** → **자세히 표시** → **그래도 유지**
- **Chrome**: 다운로드 목록에서 **유지** (또는 "위험한 파일 다운로드")

## 필요한 것
- Windows 10 / 11 (64비트)
- 디스크 여유 공간 약 5GB, 메모리 8GB 이상 권장
- 처음 실행할 때 인터넷 연결

## 지우기
Windows 설정 → 앱 → **AI 글 탐지기** → 제거

※ AI 판정은 통계적 추정이라 틀릴 수 있어요. 결과만으로 부정행위를 단정하지 말고 참고 자료로만 써 주세요.
